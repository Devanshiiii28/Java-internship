# Student Management System (Java)

## 📌 Project Overview
This project is a **menu-driven Student Management System** developed using **Java Collections Framework**.  
It allows users to manage student records efficiently by performing operations such as adding, searching, updating, deleting, and sorting students.

The project is part of a **30 Days Java Internship Assignment** and demonstrates core Java concepts.

---

## 🎯 Features
- Add a new student
- Display all students
- Search student by ID
- Update student marks
- Remove student by ID
- Sort students by marks (Descending order)
- Menu-driven console interface

---

## 🛠 Technologies & Concepts Used
- Java
- Collections Framework (`ArrayList`)
- Object-Oriented Programming (OOP)
- Encapsulation (private variables, getters & setters)
- `equals()` and `hashCode()` methods
- Comparator for sorting
- Exception Handling
- Scanner & Switch-Case
